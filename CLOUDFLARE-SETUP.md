# Подключение библиотеки Cloudflare R2 для CT26

## 1. Опубликовать код Cloudflare Worker

Cloudflare → Workers & Pages → ct26-library-api → Edit code.
Заменить код обработчика целиком содержимым `cloudflare-worker.js`, нажать Deploy.
Если Worker создан через браузер, скопируйте содержимое файла в `worker.js` в редакторе Cloudflare.

## 2. Переменные и R2

В Worker → Settings → Bindings убедиться:
- Variable name `LIBRARY_BUCKET`
- Bucket `ct26-library`

В Worker → Settings → Variables and Secrets → Add variable:
- Name: `FIREBASE_PROJECT_ID`
- Value: `ct-25-26`
- Type: Text (не секрет)
Сохранить и применить изменение к Production.

Адрес Worker: https://ct26-library-api.lukshaolga1982.workers.dev
Проверка в браузере: откройте .../health — должно вернуться `{ "ok": true }`.

## 3. Firestore Rules

Firebase Console → Firestore Database → Rules. Заменить правила содержимым файла `firestore.rules`, опубликовать.
ВАЖНО: не публикуйте только фрагмент правил, заменяя им полные правила: в архиве сохранены все прежние правила, и добавлены два новых раздела.

## 4. GitHub Pages

Поместить изменённые файлы `app.js`, `styles.css`, `index.html` в корень репозитория сайта.
Worker и инструкцию можно сохранить в репозитории, но Worker НЕ запускается из GitHub — его нужно отдельно опубликовать в Cloudflare.
Не публикуйте файлы с секретами и приватными ключами.

## 5. Проверка

1. Войти учителем → «Справочник» → загрузить небольшой PDF (до 25 МБ).
2. Назначить страницу одному ученику, группе или всем.
3. Войти учеником → «Справочник» → открыть материал → «Я повторил(а)».
4. Войти учителем → увидеть число отметивших повторение.

## Ограничения первой версии

- PDF открывается встроенным браузерным просмотрщиком по ссылке `#page=...`: переход на страницу зависит от браузера (PDF.js пока не встроен).
- Worker проверяет действительный Firebase ID-токен и принадлежность аккаунта учителю, но ученик, вошедший в систему, технически может получить любой PDF своего учителя по известному идентификатору, даже если соответствующее задание ему не назначено. Это библиотека справочников, не хранилище конфиденциальных документов.
- В Firestore студенты могут получать метаданные назначений своего учителя, хотя интерфейс показывает только назначенные им задания. Не используйте в комментариях конфиденциальные данные других учеников.
- Не проверено на реальном аккаунте Cloudflare/Firebase: понадобится выполнить шаги 1–5.
- Загрузка / удаление справочников и назначения доступны только учителю. Не забудьте опубликовать новые Firestore Rules.
- Если сайт живёт на собственном домене, а не `*.github.io`, добавьте этот домен в проверку допустимых Origin в Worker.
