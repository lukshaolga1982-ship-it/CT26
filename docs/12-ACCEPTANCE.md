# 12. Критерии приёмки

## Доступ и классы

- [ ] Учитель не может получить доступ к чужому классу.
- [ ] Ученик вступает только по действующему приглашению.
- [ ] Истёкший/отозванный/исчерпанный код отклоняется.
- [ ] Ученик не видит список/результаты других учеников.
- [ ] Пользователь не назначает себе роль учителя.

## Назначения

- [ ] Доступны full, blocks, selected, random и retry mistakes.
- [ ] Реализованы все 10 заявленных блоков.
- [ ] Случайный состав фиксируется при публикации.
- [ ] Настраиваются сроки, таймер, попытки и feedback policy.
- [ ] После публикации состав нельзя незаметно изменить.

## Попытка

- [ ] Ответы автосохраняются и восстанавливаются после refresh.
- [ ] Таймер проверяется сервером.
- [ ] Дедлайн/лимит попыток нельзя обойти клиентом.
- [ ] Повторная сдача идемпотентна.
- [ ] После сдачи ответ нельзя изменить.
- [ ] Пустые ответы корректно оцениваются в 0.

## Оценивание

- [ ] А даёт 1, Б даёт 2, максимум 62.
- [ ] Все 63 соответствия шкалы совпадают с конфигурацией.
- [ ] Полный результат 62 равен 100.
- [ ] Неполной работе не присваивается официальный `testScore`.
- [ ] Б поддерживает нормализацию и несколько допустимых ответов.
- [ ] Ручной review пересчитывает результат и создаёт audit event.

## Обратная связь

- [ ] Каждая из 5 политик соблюдается по серверному времени.
- [ ] Ключ нельзя прочитать напрямую из Firestore/API клиента.
- [ ] Retry содержит только ошибки выбранной попытки.

## Учительский кабинет

- [ ] Видны статусы, попытки, баллы, процент, время и ошибки.
- [ ] Есть аналитика по номеру и блоку.
- [ ] Экспорт соответствует фильтрам и защищён от CSV injection.

## Контент

- [ ] В системе 5 ЦЭ + 5 ЦТ вариантов.
- [ ] Каждый вариант содержит А1–А18 и Б1–Б22.
- [ ] Текст и ключи дважды сверены.
- [ ] Непроверенное задание нельзя назначить.

## Качество

- [ ] Основные потоки работают на мобильном и desktop.
- [ ] Навигация и тест доступны с клавиатуры.
- [ ] Rules unit tests и E2E проходят в CI.
- [ ] App Check и budget alerts включены.
- [ ] Секретов/ключей/PII нет в Git history.
