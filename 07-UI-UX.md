# 07. Интерфейсы и UX

## Общие требования

Адаптивный интерфейс, русский язык навигации, английский текст заданий. Не полагаться только на цвет. Все элементы доступны клавиатурой. Перед уходом с несохранённым ответом — предупреждение.

## Публичные страницы

- `/` — назначение сервиса и вход;
- `/login`, `/register`, `/forgot-password`;
- `/join/:code` — принятие приглашения;
- `/privacy`, `/terms`.

## Кабинет ученика

- `/student` — активные, будущие, завершённые и просроченные работы;
- `/student/assignments/:id` — условия и доступные попытки;
- `/student/attempts/:id` — решение;
- `/student/results/:id` — результат/обратная связь;
- `/student/progress` — динамика и блоки.

### Экран попытки

- название, прогресс, таймер, статус сохранения;
- навигатор по номерам с состояниями: пусто/отвечено/помечено;
- stimulus закрепляется рядом с относящимися вопросами;
- «Назад», «Далее», «Пометить», «Завершить»;
- подтверждение сдачи с числом пустых ответов;
- при разрыве сети — явный индикатор и очередь локальных изменений;
- после истечения срока — read-only.

## Кабинет учителя

- `/teacher` — обзор классов и работ;
- `/teacher/classes` и `/teacher/classes/:id`;
- `/teacher/invites`;
- `/teacher/assignments/new` — мастер создания;
- `/teacher/assignments/:id/results` — ведомость;
- `/teacher/attempts/:id` — детальная проверка;
- `/teacher/analytics` — анализ блоков/номеров;
- `/teacher/content` — только для доступного банка.

### Мастер назначения

1. Класс и название.
2. Режим и состав.
3. Сроки/таймер/попытки.
4. Перемешивание и политика ответа.
5. Предпросмотр.
6. Публикация.

В случайном режиме до публикации показать итоговый состав и дать «перегенерировать». После публикации seed и IDs фиксируются.

### Ведомость

Колонки: ученик, статус, попытки, первичный балл, максимум, процент, тестовый балл (если применим), длительность, дата сдачи. Фильтры и экспорт. Нужен горизонтально прокручиваемый мобильный вариант либо карточки.

## Состояния интерфейса

Для каждой страницы: loading skeleton, empty, permission denied, offline, recoverable error, fatal error. Ошибка сохранения ответа не должна маскироваться.

## Доступность

- semantic HTML/fieldset/legend для вариантов;
- видимый focus ring;
- aria-live для сохранения и таймера (без ежесекундного спама);
- таймер предупреждает на 10 и 5 мин;
- масштабирование до 200%;
- кликабельные зоны не менее 44×44 px;
- таблицы имеют заголовки;
- графики сопровождаются табличными данными.

## Дизайн-токены

Определить CSS variables для цветов, spacing, radius, shadows и typography. Статусы ошибок/успеха не кодировать только красным/зелёным. Поддержка тёмной темы не обязательна для MVP.
