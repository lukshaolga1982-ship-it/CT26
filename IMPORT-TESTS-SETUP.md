# Импорт тестов и управление доступом

1. На GitHub Pages обновите `app.js`, `styles.css`, `index.html` (или опубликуйте содержимое папки сайта целиком).
2. В Firebase Console → Firestore Database → Rules опубликуйте `firestore.rules`. Прежде чем заменять правила, сравните их с текущими правилами проекта и сохраните резервную копию.
3. В кабинете учителя: Тесты → «Загрузить Word / PDF» → выберите DOCX или PDF (до 15 МБ).
4. Проверьте распознанные номера, текст и варианты. Добавьте правильные ответы. Можно сохранить черновик без ключей, однако для открытия ученикам правильные ответы обязательны.
5. Новый тест сохраняется со статусом «Закрыт». Нажмите «Открыть доступ» после проверки, а затем «Закрыть доступ», когда потребуется.
6. Для исправления опубликованного теста нажмите «Редактировать». Ранее выполненные попытки сохраняются.

## Ограничения
- Импорт основан на текстовом содержимом DOCX/PDF и эвристическом распознавании нумерации. Таблицы, колонки, иллюстрации и сложные форматы могут требовать ручных правок.
- PDF-сканы без текстового слоя не поддерживаются: нужен OCR.
- Импорт DOCX/PDF загружает библиотеки Mammoth и PDF.js с CDN, поэтому в момент импорта нужен Интернет.
- Доступ открывается/закрывается для **авторских тестов**. Встроенные в JS-файлы демонстрационные/готовые варианты пока не имеют индивидуального переключателя. Их нельзя надёжно скрыть, пока они статически включены в открытые файлы сайта.
- Текущий формат приложения хранит `gradingAnswers` в документах тестов, которые учащиеся могут читать. Для защищённого экзаменационного режима следует перенести ключи ответов в закрытую серверную проверку. Это ограничение существующей архитектуры.
- Изменение статуса теста не прерывает попытку, начатую до закрытия доступа. Если это необходимо, потребуется отдельная серверная проверка при отправке.
