# ЦЭ/ЦТ по английскому языку

Рабочая версия сайта для учителя и учеников на бесплатном тарифе Firebase Spark.

## Что уже готово

- отдельный реальный вход учителя по email и ученика по выданному логину;
- создание аккаунтов учеников из кабинета учителя без Cloud Functions;
- удаление ученика из списка с немедленной блокировкой его кабинета;
- создание, редактирование и удаление авторских тестов учителя;
- 35 интерактивных работ из новых файлов: ЦЭ 2026 (1–5), ЦТ 2026 (1–5), аналоги 2025 (26–40) и аналоги 51–60;
- каждый вариант открывается отдельно, без PDF-сборника;
- старый банк отключён; на сайте показываются только новые источники;
- задания перенесены в нативный текст, а ключи Teacher's Copy отделены от ученической части;
- задания части A имеют интерактивный выбор номера ответа, задания части B — отдельные поля ввода;
- автоматическая проверка: часть A — 1 балл, часть B — 2 балла;
- перевод 0–62 первичных баллов в тестовые 0–100;
- сохранение попыток, результатов и ошибок в Firestore;
- каталоги материалов 2020–2025 с обязательной пометкой года;
- нормализация регистра, пробелов, апострофов и дефисов в части B;
- сохранение ответов в Firestore и автоматическая проверка при входе учителя.
- личные сообщения между учителем и каждым учеником с отметкой непрочитанных;
- бесплатные почтовые уведомления об отправке теста через Google Apps Script.

## Настройка Firebase

1. Включите Authentication → Email/Password.
2. Создайте Firestore Database в production mode.
3. Создайте пользователя учителя в Authentication.
4. Создайте документ `users/{UID_УЧИТЕЛЯ}`:

```text
role: teacher
displayName: Ольга Лукша
email: lukshaolga1982@gmail.com
active: true
```

5. Добавьте `lukshaolga1982-ship-it.github.io` в Authentication → Settings → Authorized domains.
6. В корневой папке проекта выполните:

```bash
npm install -g firebase-tools
firebase login
firebase use --add
firebase deploy --only firestore:rules,firestore:indexes
```

## Публикация на GitHub Pages

Загрузите содержимое папки проекта в корень репозитория `CT_25_26`, затем включите:

`Settings → Pages → Deploy from a branch → main / root`.

При первом входе учителя сайт публикует метаданные пяти готовых тестов и закрытые ключи ответов в Firestore. Ключи доступны только учителю и серверной функции проверки.

## Основные файлы

- `index.html` — входная страница;
- `app.js` — кабинеты, тестирование и работа с Firebase;
- `data/tests.js` — структура пяти вариантов и исходные ключи для первичной публикации;
- `firebase-service.js` — Firebase SDK;
- `firestore.rules` — правила безопасности;
- `functions/index.js` — необязательный вариант для будущего перехода на Blaze;
- `firebase-config.js` — публичная конфигурация веб-приложения.

Не загружайте в репозиторий пароли и Service Account JSON.

Инструкция по почтовым уведомлениям находится в `EMAIL_SETUP.md`.
