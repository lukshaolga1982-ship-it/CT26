# Платформа интерактивных тестов ЦЭ/ЦТ по английскому языку

Комплект проектной документации для создания сайта учителя на **React + TypeScript + Firebase**.

## Цель

Сайт позволяет учителю приглашать учащихся, назначать им полные тесты и тренировки, автоматически проверять ответы, рассчитывать первичный и тестовый балл, анализировать ошибки и экспортировать результаты.

## Подтверждённый состав исходного сборника

- 44 страницы-скана;
- 5 вариантов ЦЭ и 5 вариантов ЦТ;
- каждый полный вариант: А1–А18 и Б1–Б22;
- часть А: 18 заданий × 1 первичный балл;
- часть Б: 22 задания × 2 первичных балла;
- максимум: 62 первичных балла = 100 тестовых баллов.

> OCR нельзя публиковать без визуальной сверки с PDF. У каждого задания и ключа предусмотрен статус проверки.

## Рекомендуемый стек

- React 19, TypeScript, Vite;
- React Router;
- Firebase Authentication;
- Cloud Firestore;
- Cloud Functions for Firebase v2;
- Firebase Hosting;
- Cloud Storage (только если понадобятся изображения/аудио);
- Firebase App Check;
- Firebase Emulator Suite;
- Vitest + Testing Library + Playwright;
- GitHub Actions.

## Конфигурация

- `data/config/score-scale.json` — официальная шкала 0–62 → 0–100 с изображения;
- `data/config/blocks.json` — заданные блоки;
- `data/schema/test.schema.json` — JSON Schema варианта;
- `examples/test.example.json` — безопасный пример структуры без текста сборника и ключей;
- `firebase/firestore.rules.template` — шаблон правил;
- `firebase/firestore.indexes.json` — рекомендуемые индексы.

## Важное правило защиты

Правильные ответы не должны находиться в публичной части репозитория или передаваться ученику до разрешённого момента. Проверка выполняется Cloud Function. Закрытые ключи импортируются в отдельную серверную коллекцию Firestore.

## Начало работы

1. Создать Firebase-проект и включить Authentication/Firestore/Functions/Hosting/App Check.
2. Реализовать коллекции и функции по документам 03–06.
3. Поднять Emulator Suite и пройти сценарии из документа 09.
4. Оцифровать сборник по процедуре документа 08.
5. Публиковать только задания со статусом `verified`.
6. Настроить GitHub Actions и Firebase Hosting по документу 10.

## Решения, принятые по умолчанию

- Учитель создаёт приглашение (ссылка/код), учащийся принимает его после входа.
- Ученик не может сам назначить себе роль учителя.
- Настройка показа ответов задаётся отдельно для каждого назначения.
- Результат фиксируется сервером; клиентский расчёт используется лишь для предварительного отображения.
- Для неполных тренировок показываются первичные баллы, максимум и процент. Официальная шкала 0–100 применяется только к полному тесту из 62 баллов.
