# 06. Оценивание и проверка

## Первичные баллы

- А1–А18: по 1 баллу, максимум 18.
- Б1–Б22: по 2 балла, максимум 44.
- Полный тест: 62 первичных балла.

```ts
awarded = isCorrect ? (part === "A" ? 1 : 2) : 0;
primary = sum(awarded);
```

Частичных баллов внутри одного задания в MVP нет. Ручной пересмотр Б назначает 0 или 2.

## Перевод в тестовый балл

Для полного теста ровно из А1–А18 и Б1–Б22 применяется lookup из `data/config/score-scale.json`. Интерполяция и математическое округление запрещены.

Примеры: 5→8, 31→49, 44→63, 58→87, 62→100.

### Неполные работы

Официальная таблица рассчитана на максимум 62. Для блока/подборки показывать:

- `primaryScore / maxPrimaryScore`;
- процент `primaryScore / maxPrimaryScore × 100`;
- количество верных заданий.

Поле `testScore` оставлять `null`, если работа не содержит полный канонический набор. Не выдавать процент блока за официальный тестовый балл.

## Часть А

Ответ хранится как стабильный `optionId`, а не как позиция после перемешивания. Правильность: строгое равенство с `correctOptionId`.

## Часть Б: нормализация

Порядок по умолчанию:

1. Unicode NFKC;
2. trim;
3. lowercase в locale-independent режиме;
4. заменить `’`/`‘`/`ʼ` на `'`;
5. заменить типографские тире на `-`;
6. схлопнуть последовательности пробельных символов;
7. опционально убрать пробелы вокруг дефиса/апострофа.

Пунктуацию, пробелы внутри фразы, дефисы или апострофы нельзя безусловно удалять: это может менять корректность. Политика задаётся в ключе задания.

```ts
type Normalization = {
  unicode: "NFKC";
  caseInsensitive: boolean;
  trim: boolean;
  collapseWhitespace: boolean;
  canonicalApostrophe: boolean;
  canonicalHyphen: boolean;
  removeAllSpaces?: boolean;
};
```

После нормализации выполняется точное сравнение с каждым `acceptedAnswers`. Допустимые варианты предварительно нормализуются тем же алгоритмом.

## Несколько ответов и ручная проверка

Ключ может содержать несколько лингвистически допустимых вариантов. Если автоматическая проверка дала false, учитель может назначить true/false вручную с причиной. Нечёткое расстояние (Levenshtein) разрешено только как подсказка `needsReview`, но не как автоматическое начисление.

## Показ ответа

Функция обратной связи проверяет политику и серверное время. До разрешения возвращаются только баллы/статус, без `acceptedAnswers`, `correctOptionId` и объяснения.

## Пересчёт

`scoringVersion` и версии ключей фиксируются. При исправлении ключа администратор запускает явный batch/recalculation. Все изменённые результаты журналируются; учитель и ученик получают пометку «результат пересчитан».

## Контрольные тесты

Обязательны 63 unit-теста шкалы для входов 0…62, тесты границ, всех блоков, Unicode/пробелов/апострофов/дефисов, нескольких ответов и повторной идемпотентной сдачи.
