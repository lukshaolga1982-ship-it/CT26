# Выбор учеников для авторских тестов

Обновите `app.js` на GitHub и правила `firestore.rules` в Firebase Console → Firestore Database → Rules (сделайте копию действующих правил перед заменой).

В разделе «Тесты» у каждой авторской работы появилась кнопка «Все учащиеся» / «Выбраны: N». Откройте её, выберите режим «Только выбранным учащимся», отметьте нужных детей и сохраните. Кнопка «Открыть доступ» / «Закрыть доступ» продолжает управлять публикацией независимо от списка.

ВАЖНО: после обновления правил ранее созданные авторские тесты, у которых ещё нет поля audienceMode, не будут видны ученикам, пока вы не зайдёте в настройки аудитории и не сохраните «Все учащиеся» или выбранный список. Учителю они видны.

Запросы для учеников теперь ограничены режимом доступа на уровне Firestore. Для них Firebase может потребовать создать составные индексы по полям `teacherId` + `status` + `audienceMode` и `teacherId` + `status` + `allowedStudentIds`; при появлении ошибки Firestore откройте ссылку на создание индекса в консоли браузера и дождитесь его построения. Для многих проектов индексы по умолчанию уже подходят.

Проверка: зайдите в два ученических аккаунта (назначенный и неназначенный), убедитесь, что тест виден только назначенному. Затем закройте тест: он должен исчезнуть у обоих.

Ограничение: данное изменение относится к авторским тестам; встроенный банк ЦЭ/ЦТ остаётся доступен по прежним правилам.
